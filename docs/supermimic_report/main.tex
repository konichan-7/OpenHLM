\begin{insight}{报告结论先读}
该仓库实现了 SuperMimic 的核心三阶段训练循环：仿真采样、世界模型拟合、基于想象轨迹的 BPTT 策略与价值学习。它是面向 LAFAN1 的\textbf{非官方、部分范围复现}，不能直接视为论文全部实验的官方代码。本文将论文规定、代码事实、解释性推导和已运行验证明确区分。
\end{insight}
